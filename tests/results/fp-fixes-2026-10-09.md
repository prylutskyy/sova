# False-positive fixes: four regression cases

Date: 2026-10-09

## Changes

- `OFF_PLATFORM_REDIRECT` now requires both a messenger indicator and an explicit move/contact action in the current message. Mere mentions, comparisons, and the infinitive in a negated example do not form this intent. Action matching is normalized and retains support for obfuscated messenger names.
- Identity-document mentions now require a request verb; a shipping-label question containing “номер документа” is not enough to form `IDENTITY_PROBING`.
- The semantic reward vocabulary no longer treats “підтримка” (support) as financial incentive.
- The pure military-vector fallback now requires a polite media request about a specific military or critical-infrastructure target. Generic address/number language and similarity alone cannot cause a military intent or `LOCK_INPUT`.
- Added four regression tests asserting all target cases remain `ALLOW` through both direct and stateful classification.
