## Виявлені уточнення

У README й посібнику виправлено трактування зеленого Vault на довіреному сайті та описано ширшу область блокування вводу. Критичне «Зрозуміло» не прирівнюється до «Зняти». Вербування описано окремо від криптосценарію та семантичної схожості. Код застосунку й метрики не змінювалися.
